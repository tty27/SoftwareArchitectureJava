🏥 Healthcare Management System

Java Software Architecture Assignment

A Java-based healthcare management system developed as part of a Software Architecture assignment during my Software Engineering studies.

The project explores the development of a structured software application within a healthcare context, with an emphasis on applying programming concepts and organising application code.

📌 Project Overview

Healthcare management applications need to organise information and support reliable workflows. This project uses a healthcare management scenario to practise software development and architecture concepts in Java.

The repository contains the `HealthcareManagementSystem` project.

🎯 Project Objectives

- Apply Java programming concepts to a practical application.
- Organise application code into a maintainable structure.
- Practise translating requirements into software components.
- Develop a better understanding of software design and architecture.
- Strengthen debugging and problem-solving skills.

🛠️ Technology

- Programming Language: Java
- Development Environment: Java-compatible IDE or development tools
